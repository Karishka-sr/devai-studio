DevAI Studio 2.12.0 — PC-версия для Windows
============================================

Установка
1. Запустите DevAI-Studio-Setup-2.12.0.exe.
2. Выберите Windows 7, Windows 10 или Windows 11.
3. Установите программу и запустите с ярлыка на рабочем столе.

Первый запуск
1. Откройте вкладку «Настройки».
2. Выберите провайдера: OpenAI, Gemini, Claude или свой OpenAI-совместимый API.
3. Введите Base URL, модель и API-ключ.
4. Нажмите «Проверить», затем «Сохранить».

Vexel
Vexel — Android-конструктор, который входит в DevAI Studio без изменений.
APK лежит рядом с программой: DevAI-Android.apk.
Установите его на телефон или Android-эмулятор (BlueStacks, LDPlayer,
Android Studio Emulator). На вкладке «Vexel» есть кнопки для ADB.

Автор:
Конструктор взят у https://t.me/cheburek_dev, Разрешение есть,
оригинальный конструктор Vexel скачивать с этого тгк.

Данные
Настройки: %APPDATA%\DevAI Studio\settings.properties
История чата: %APPDATA%\DevAI Studio\history.txt

JRE
В установщик входит Java Runtime Environment 8 (x64), поэтому отдельная
установка Java не нужна.
