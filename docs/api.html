02

Интеграция

Подключение за одну минуту

Любой клиент, который умеет OpenAI Chat Completions, подойдёт без изменений.

$ curl "https://work-2-nizvyfgvcqicrkif.prod-runtime.all-hands.dev/v1/chat/completions" \
  -H "Authorization: Bearer $DEVAI_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "devai-core-4.0",
    "messages": [{"role": "user", "content": "Напиши hello world на Kotlin"}],
    "stream": false
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://work-2-nizvyfgvcqicrkif.prod-runtime.all-hands.dev/v1",
    api_key="devai-sk-...",
)

response = client.chat.completions.create(
    model="devai-core-4.0",
    messages=[{"role": "user", "content": "Привет!"}],
)
print(response.choices[0].message.content)
const response = await fetch(
  "https://work-2-nizvyfgvcqicrkif.prod-runtime.all-hands.dev/v1/chat/completions",
  {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${DEVAI_KEY}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      model: "devai-core-4.0",
      messages: [{ role: "user", content: "Привет!" }],
    }),
  },
);

const data = await response.json();
console.log(data.choices[0].message.content);
01

OpenAI-совместимость

Работает с OpenAI SDK, LangChain, LlamaIndex, Ollama-клиентами и любым HTTP-клиентом.

02

Потоковые ответы

Передайте stream: true и получайте SSE-чанки по мере генерации.

03

Ключи без хранения

Сервер хранит только SHA-256 ключа. Сам ключ показывается один раз.

04

Локальная модель

Qwen2.5 0.5B работает на сервере. Запросы не уходят сторонним провайдерам.

03

В приложении

Ключ в DevAI Studio

Один ключ работает и в браузере, и в Android-приложении. Ключ хранится в Android Keystore.

01

Откройте провайдеры

В приложении: «Настройки» → «Провайдеры» → «DevAI Core».

02

Вставьте ключ

Нажмите «Ключ», вставьте значение из этой страницы и сохраните. Повторно ключ не показывается.

03

Обновление v0.5

Сам учится. Сам проверяет.

24 / 7

Автообучение читает документацию и сайты. Новые знания публикуются в канале DevAI, а комментарии разбирает бот.

любая ссылка

Публичные http(s)-адреса, включая t.me. DevAI открывает страницу, читает текст и проверяет редирект, домен и форму пароля.

скан файла

Пришлите файл или ссылку в чат. В ответе будет вердикт, риск 0–100, SHA-256 и найденные признаки. Файлы не запускаются.

честно

Это эвристический антивирус, а не ClamAV. Он ловит типовые угрозы, но не заменяет проверку в песочнице.

API: POST /v1/scan с url, text или content_base64. Админ: GET /admin/learning, POST /admin/learning/run, POST /admin/learning/url, POST /admin/learning/text.

05

Правила

Лимиты и честность

60 rpm

Запросов в минуту на ключ. Достаточно для чата и небольших ботов.

1024 tok

Максимум новых токенов в одном ответе. Входной контекст — до 2048 токенов.

3 / day

Новых ключей с одного IP в сутки. Это защита от автоматического спама.

1 / proc

Одна генерация одновременно. Модель работает на CPU — ответ может занять несколько секунд.

Ключ — личный. Не публикуйте его в открытых репозиториях, не вставляйте в клиентские приложения и не перепродавайте доступ. При злоупотреблении ключ можно отозвать.
