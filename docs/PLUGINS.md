## 1. Коротко: что это и зачем

Плагин `.devai` — это файл, который добавляет в DevAI Studio новые возможности:

- **команды** — кнопки/пункты в меню плагинов, которые преобразуют ваш текст;
- **инструменты** — функции, которые **ИИ вызывает сам**, когда ему нужно посчитать слова, перевернуть строку, извлечь список задач, подготовить запрос к другому сервису и т.п.

Главное отличие версии 2.0: плагин — это **настоящий исполняемый код на Lua**, а не просто текст промпта. Lua работает внутри приложения через открытую библиотеку **LuaJ**. Код выполняется в ограниченной песочнице: без файлов, сети, `os`, `io`, `require` и Java-классов.

Простыми словами:

- раньше плагин мог только подставить текст в сообщение;
- теперь плагин может **выполнить алгоритм** и вернуть результат;
- ИИ может **вызвать функцию плагина как инструмент** и продолжить ответ с учётом результата.

## 2. Что такое плагин `.devai`

`.devai` — обычный текстовый файл. Внутри может быть:

1. **Lua-плагин** — файл с кодом, который возвращает таблицу с полями `name`, `description`, `commands`, `tools`.
2. **DPL-плагин** — старый простой файл из строк `ключ = значение`, где главное поле — `prompt`.

Приложение определяет тип автоматически:

- если файл похож на Lua (есть `return`, `function` или `commands`), оно пытается загрузить его как Lua;
- если Lua не загрузился, оно пробует старый DPL-формат;
- если не получилось ни то, ни другое, импорт завершается ошибкой.

### Что получает пользователь

После импорта плагин появляется в разделе:

**Инструменты → Плагины**

В чате появляется кнопка:

**🧩 Плагины**

Там видны команды плагина. Инструменты ИИ отдельно нажимать не нужно: они уходят модели вместе с запросом, если провайдер поддерживает tool calling.

## 3. Чем команда отличается от инструмента ИИ

Это самое важное место. Прочитайте его до написания плагина.

| | Команда | Инструмент ИИ |
|---|---|---|
| Кто запускает | Пользователь | Модель |
| Где видно | Меню «🧩 Плагины» | Внутри ответа ИИ, автоматически |
| Что получает | Текст из поля сообщения | JSON-аргументы от модели |
| Что возвращает | Текст, который подставляется в поле сообщения | Текст, который модель видит как результат инструмента |
| Когда использовать | «Переведи в верхний регистр», «Сделай заготовку промпта» | «Посчитай слова», «Извлеки задачи», «Проверь формат» |
| Нужен ли tool calling | Нет | Да, только OpenAI-совместимые провайдеры |

### Пример команды

Пользователь пишет:

```text
привет мир
```

Нажимает **🧩 Плагины → /upper**. В поле появляется:

```text
ПРИВЕТ МИР
```

### Пример инструмента

Пользователь пишет:

```text
Посчитай, сколько слов в тексте: «Сегодня хорошая погода».
```

Модель решает вызвать `word_count`, приложение выполняет Lua-функцию, возвращает `Слов: 3`, и модель отвечает пользователю уже с этим числом.

## 4. Быстрый старт за 5 минут

### Шаг 1. Откройте плагины

**Инструменты → Плагины**.

Там уже есть примеры:

- «Суммаризатор» — старый DPL-промпт;
- «Ревью кода» — старый DPL-промпт;
- «Lua-инструменты» — настоящий Lua-плагин с командами и инструментами.

### Шаг 2. Попробуйте команду

1. Откройте чат.
2. Напишите любой текст, например `привет`.
3. Нажмите **🧩 Плагины**.
4. Выберите **Lua-инструменты /upper**.
5. В поле появится `ПРИВЕТ`. Отправьте сообщение.

### Шаг 3. Попробуйте инструмент ИИ

1. Убедитесь, что выбран OpenAI-совместимый провайдер.
2. Напишите: «Посчитай слова в тексте: один два три».
3. Модель может вызвать `word_count`.
4. В ответе появится результат.

Если модель не вызывает инструмент, попросите явно:

```text
Используй инструмент word_count для текста: один два три
```

### Шаг 4. Импортируйте свой плагин

1. Создайте файл `my-plugin.devai`.
2. Вставьте код из [шаблона](#17-шаблоны-для-копирования).
3. В приложении нажмите **Импорт .devai**.
4. Выберите файл.
5. Плагин появится в списке.

## 5. Установка, удаление и хранение плагинов

### Импорт

**Инструменты → Плагины → Импорт .devai**.

Приложение:

1. читает файл;
2. проверяет синтаксис;
3. сохраняет копию во внутреннюю папку приложения;
4. показывает плагин в списке.

### Где хранятся файлы

Во внутреннем хранилище приложения:

```text
files/plugins/<имя>.devai
```

Это не публичная папка. Другие приложения туда не пишут.

### Удаление

В списке плагинов нажмите **Удалить**. Файл удаляется из внутренней папки.

### Встроенные примеры

При открытии списка приложение само копирует недостающие примеры из assets. Если вы удалили пример, он может появиться снова при следующем открытии списка. Это нормально.

### Ограничения импорта

- файл должен быть текстовым;
- расширение — `.devai`;
- синтаксис Lua или DPL должен быть корректным;
- если плагин не загрузился, приложение покажет ошибку импорта.

Рекомендуемый размер — до 64 КБ. Технически можно больше, но большой файл дольше проверять и сложнее поддерживать.

## 6. Lua с нуля: минимум, которого хватит

Если вы уже знаете Lua — переходите к [структуре плагина](#7-структура-lua-плагина). Если нет — этого раздела достаточно для большинства плагинов.

### 6.1. Комментарии

```lua
-- одна строка

--[[
многострочный
комментарий
]]
```

### 6.2. Переменные

```lua
local name = "DevAI"
local count = 3
local enabled = true
local nothing = nil
```

`local` означает, что переменная видна только внутри файла/функции. Используйте `local` почти всегда.

### 6.3. Строки

```lua
local a = "привет"
local b = 'мир'
local c = [[длинная
строка]]
```

Склейка строк:

```lua
local text = "привет" .. " " .. "мир"
```

Длина строки:

```lua
local n = string.len("привет") -- 6 байт
```

Важно: `string.len` считает **байты**, а не символы. Для русского текста это может быть больше, чем количество букв.

### 6.4. Условия

```lua
if count > 0 then
  return "есть"
elseif count == 0 then
  return "пусто"
else
  return "минус"
end
```

Сравнения: `==`, `~=`, `>`, `<`, `>=`, `<=`.

### 6.5. Циклы

```lua
for i = 1, 3 do
  -- i = 1, 2, 3
end

for _, value in ipairs({ "a", "b" }) do
  -- value = "a", затем "b"
end

while count > 0 do
  count = count - 1
end
```

### 6.6. Функции

```lua
local function greet(name)
  return "Привет, " .. name
end

local text = greet("Мир")
```

Функция может быть значением:

```lua
local run = function(input)
  return string.upper(input)
end
```

### 6.7. Таблицы

Таблица — это и массив, и словарь.

Массив:

```lua
local items = { "один", "два", "три" }
local first = items[1] -- "один"
local count = #items -- 3
```

Словарь:

```lua
local user = {
  name = "Аня",
  age = 25,
}
local name = user.name
```

Вложенные таблицы:

```lua
local plugin = {
  name = "Мой плагин",
  commands = {
    { name = "/test" }
  }
}
```

### 6.8. Полезные строковые функции

```lua
string.upper(s)          -- ВЕРХНИЙ РЕГИСТР
string.lower(s)          -- нижний регистр
string.len(s)            -- длина в байтах
string.sub(s, 1, 3)      -- первые 3 байта
string.find(s, "мир")    -- позиция или nil
string.gsub(s, "а", "б") -- замена
string.gmatch(s, "%S+")  -- перебор слов
string.format("%d", 42)  -- форматирование
string.rep("x", 3)       -- "xxx"
string.reverse(s)        -- переворот
```

Пример подсчёта слов:

```lua
local function word_count(text)
  local n = 0
  for _ in string.gmatch(text or "", "%S+") do
    n = n + 1
  end
  return n
end
```

### 6.9. Полезные табличные функции

```lua
table.insert(t, value)
table.remove(t, index)
table.concat(t, ", ")
#t
```

### 6.10. Математика

```lua
math.floor(3.7) -- 3
math.ceil(3.1)  -- 4
math.max(1, 5)  -- 5
math.min(1, 5)  -- 1
```

### 6.11. Ошибки

```lua
error("Что-то пошло не так")
```

Можно ловить:

```lua
local ok, result = pcall(function()
  return 1 / 0
end)
```

В плагине лучше возвращать понятную строку, а не ронять всё приложение.

## 7. Структура Lua-плагина

Минимальный плагин:

```lua
return {
  name = "Мой плагин"
}
```

Но полезный плагин обычно выглядит так:

```lua
local plugin = {
  name = "Название",
  description = "Что делает плагин",
  version = "1.0",
  author = "Ваше имя",

  commands = {
    -- команды для пользователя
  },

  tools = {
    -- инструменты для ИИ
  }
}

return plugin
```

### Обязательные и необязательные поля

| Поле | Обязательно | Что это |
|---|---|---|
| `name` | Да, для нормального вида | Название плагина |
| `description` | Нет | Описание в списке |
| `version` | Нет | Версия, по умолчанию `1.0` |
| `author` | Нет | Автор |
| `commands` | Нет | Массив команд |
| `tools` | Нет | Массив инструментов для ИИ |

Плагин без `commands` и `tools` загрузится, но будет бесполезен.

### Почему `return` в конце

Lua-файл должен вернуть таблицу. Приложение вызывает файл как функцию и читает результат. Если забыть `return`, плагин не загрузится.

Правильно:

```lua
local plugin = { name = "Тест" }
return plugin
```

Тоже правильно:

```lua
return { name = "Тест" }
```

Неправильно:

```lua
local plugin = { name = "Тест" }
-- нет return
```

## 8. Команды: подробно

Команда — это действие, которое запускает пользователь.

### Поля команды

| Поле | Обязательно | Что это |
|---|---|---|
| `name` | Да | Название, например `/upper` |
| `description` | Нет | Подсказка |
| `run` | Да, если нет `prompt` | Функция `run(input)` |
| `prompt` | Да, если нет `run` | Строка с `{{input}}` |

### Команда с функцией

```lua
commands = {
  {
    name = "/upper",
    description = "Верхний регистр",
    run = function(input)
      return string.upper(input)
    end
  }
}
```

Что происходит:

1. пользователь пишет `привет`;
2. выбирает `/upper`;
3. приложение вызывает `run("привет")`;
4. получает `ПРИВЕТ`;
5. подставляет результат в поле сообщения.

### Команда с промптом

```lua
commands = {
  {
    name = "/sum",
    description = "Резюме текста",
    prompt = "Сделай краткое резюме:\n\n{{input}}"
  }
}
```

`{{input}}` заменяется на текст из поля. Это удобно для промптов, но не даёт вычислений.

### Несколько команд

```lua
commands = {
  {
    name = "/upper",
    run = function(input) return string.upper(input) end
  },
  {
    name = "/lower",
    run = function(input) return string.lower(input) end
  },
  {
    name = "/reverse",
    run = function(input) return string.reverse(input) end
  }
}
```

В меню «🧩 Плагины» появятся три пункта.

### Что возвращать

Верните строку:

```lua
return "готово"
```

Можно вернуть число — приложение преобразует его в строку:

```lua
return 42
```

Можно вернуть `nil` — получится пустая строка. Лучше так не делать.

### Ограничения команд

- Команда получает только текст из поля сообщения.
- Команда не получает историю чата.
- Команда не получает API-ключи.
- Команда не должна делать сетевые запросы: сети в песочнице нет.
- Результат команды — это новый текст сообщения, а не ответ ИИ.

## 9. Инструменты для ИИ: подробно

Инструмент — это функция, которую вызывает модель.

### Как это работает

1. Вы отправляете сообщение.
2. Приложение добавляет к запросу описания всех инструментов плагинов.
3. Модель решает: ответить сразу или вызвать инструмент.
4. Если вызвать — приложение выполняет Lua-функцию.
5. Результат возвращается модели.
6. Модель продолжает ответ.
7. Максимум 3 раунда вызовов за один запрос.

### Поля инструмента

| Поле | Обязательно | Что это |
|---|---|---|
| `name` | Да | Имя функции: латиница, цифры, `_` |
| `description` | Да | Что делает; модель читает это |
| `parameters` | Да | JSON Schema аргументов |
| `run` | Да | Функция `run(args)` |

### Пример

```lua
tools = {
  {
    name = "word_count",
    description = "Считает количество слов в тексте.",
    parameters = [[{"type":"object","properties":{"text":{"type":"string","description":"Текст"}},"required":["text"]}]],
    run = function(args)
      local n = 0
      for _ in string.gmatch(args.text or "", "%S+") do
        n = n + 1
      end
      return "Слов: " .. n
    end
  }
}
```

### Что приходит в `args`

Модель присылает JSON. Приложение превращает его в Lua-таблицу.

Если схема:

```json
{
  "type": "object",
  "properties": {
    "text": { "type": "string" },
    "limit": { "type": "integer" }
  },
  "required": ["text"]
}
```

То в Lua:

```lua
run = function(args)
  local text = args.text or ""
  local limit = args.limit or 10
  return string.sub(text, 1, limit)
end
```

### Что вернуть

Верните строку. Модель увидит её как результат инструмента.

```lua
return "Слов: " .. n
```

Не возвращайте таблицу: приложение преобразует её в строку, но лучше явно вернуть текст.

### Ошибки

Если Lua-функция упала, приложение вернёт модели строку вида:

```text
Ошибка инструмента плагина: ...
```

Модель может попробовать ещё раз или объяснить ошибку пользователю.

### Когда модель не вызывает инструмент

Причины:

- провайдер не поддерживает tool calling;
- выбран не OpenAI-совместимый формат;
- описание инструмента слишком непонятное;
- модель не поняла, зачем он нужен.

Что делать:

1. Проверьте провайдера: инструменты работают через OpenAI-совместимый API.
2. Напишите в `description` конкретно: «Считает слова. Вызывай, когда просят посчитать слова».
3. Попросите явно: «Используй инструмент word_count».
4. Упростите схему аргументов.

### Имена инструментов

Используйте латиницу, цифры и `_`:

```text
word_count
reverse_text
extract_todos
```

Не используйте пробелы, дефисы, эмодзи. Приложение всё равно очистит имя, но лучше сразу писать правильно.

### Уникальность

Имена инструментов разных плагинов не должны совпадать. Приложение добавляет префикс плагина, но лучше не создавать `word_count` в пяти плагинах.

## 10. JSON Schema для параметров

`parameters` — это строка с JSON Schema. Можно писать в длинных скобках Lua:

```lua
parameters = [[
{
  "type": "object",
  "properties": {
    "text": {
      "type": "string",
      "description": "Текст для обработки"
    }
  },
  "required": ["text"]
}
]]
```

### Простая схема

```json
{
  "type": "object",
  "properties": {
    "text": { "type": "string" }
  },
  "required": ["text"]
}
```

### Несколько полей

```json
{
  "type": "object",
  "properties": {
    "text": { "type": "string", "description": "Исходный текст" },
    "limit": { "type": "integer", "description": "Сколько символов оставить" },
    "uppercase": { "type": "boolean", "description": "Сделать верхний регистр" }
  },
  "required": ["text"]
}
```

### Список допустимых значений

```json
{
  "type": "object",
  "properties": {
    "mode": {
      "type": "string",
      "enum": ["short", "detailed"],
      "description": "Режим"
    }
  },
  "required": ["mode"]
}
```

### Массив

```json
{
  "type": "object",
  "properties": {
    "items": {
      "type": "array",
      "items": { "type": "string" },
      "description": "Список строк"
    }
  },
  "required": ["items"]
}
```

### Если схема не нужна

Инструмент без аргументов:

```json
{"type":"object","properties":{}}
```

В Lua:

```lua
run = function(args)
  return "готово"
end
```

### Можно ли передать таблицу вместо строки

Да, движок преобразует Lua-таблицу в JSON. Но строка надёжнее и понятнее. В документации используйте строку.

## 12. Песочница и безопасность

### Что доступно

- `base`: `tostring`, `tonumber`, `type`, `pairs`, `ipairs`, `pcall`, `error`, `assert`, `select`;
- `table`: `insert`, `remove`, `concat`, `sort`;
- `string`: `upper`, `lower`, `len`, `sub`, `find`, `gsub`, `gmatch`, `format`, `rep`, `reverse`;
- `math`: `floor`, `ceil`, `max`, `min`, `abs`, `random`.

### Что отключено

- `io` — нельзя читать/писать файлы;
- `os` — нельзя запускать команды и узнавать время;
- `package` — нельзя подключать модули;
- `require` — нельзя загружать чужой код;
- `load`, `loadstring`, `loadfile`, `dofile` — нельзя компилировать код на лету;
- `debug` — нельзя лезть внутрь интерпретатора;
- `luajava` — нельзя вызывать Java-классы.

### Что это значит

Плагин **не может**:

- прочитать ваши файлы;
- отправить данные в интернет;
- получить API-ключи;
- запустить системную команду;
- подключить стороннюю библиотеку.

Плагин **может**:

- обрабатывать текст;
- считать;
- форматировать;
- возвращать результат;
- зациклиться (см. ниже).

### Важное предупреждение

Это всё равно **исполняемый код**. Песочница снижает риск, но не делает любой плагин безопасным.

- Устанавливайте `.devai` только из источников, которым доверяете.
- Просматривайте код перед импортом.
- Не запускайте плагины, которые пытаются обойти ограничения.
- Бесконечный цикл `while true do end` может зависнуть. Приложение не убивает Lua-поток по таймауту.

### API-ключи

Плагин не получает ключи провайдеров. Даже если в коде написать `api_key`, это будет просто переменная.

### Сеть

Сети нет. Если плагину нужен внешний сервис, используйте **MCP-сервер**, а не Lua-плагин.

## 13. Старый формат DPL

DPL — простой текстовый формат. Он не исполняет код, а подставляет промпт.

### Поля

| Поле | Обязательно | Что это |
|---|---|---|
| `name` | Да | Название |
| `id` | Нет | Идентификатор |
| `description` | Нет | Описание |
| `command` | Нет | Команда, по умолчанию `/<id>` |
| `prompt` | Да | Текст промпта |
| `version` | Нет | Версия |
| `author` | Нет | Автор |

### Пример

```devai
name = Суммаризатор
id = summarizer
description = Делает краткое резюме текста.
command = /sum
version = 1.0
author = DevAI
prompt = Сделай краткое резюме текста. Сохрани главное, убери воду.\n\n{{input}}
```

### Ограничения DPL

- нет вычислений;
- нет инструментов ИИ;
- нет условий и циклов;
- только подстановка `{{input}}`;
- сложные промпты неудобно хранить.

### Когда использовать

- нужен простой промпт;
- не хотите писать код;
- плагин должен только менять формулировку запроса.

### Миграция на Lua

Было:

```devai
name = Суммаризатор
command = /sum
prompt = Сделай резюме:\n\n{{input}}
```

Стало:

```lua
return {
  name = "Суммаризатор",
  commands = {
    {
      name = "/sum",
      description = "Сделай резюме",
      prompt = "Сделай резюме:\n\n{{input}}"
    }
  }
}
```

## 14. MCP и плагины: в чём разница

| | Плагин `.devai` | MCP-сервер |
|---|---|---|
| Где работает | Внутри приложения | Отдельный сервер |
| Язык | Lua | Любой, обычно HTTP/JSON-RPC |
| Сеть | Нет | Да |
| Файлы | Нет | Зависит от сервера |
| API-ключи | Нет | Может требовать токен |
| Установка | Импорт файла | URL + токен |
| Для чего | Локальные вычисления и текст | Внешние сервисы и данные |

### Что выбрать

- Нужно посчитать слова, перевернуть строку, извлечь TODO — **плагин**.
- Нужно сходить в GitHub, Notion, базу данных, API — **MCP-сервер**.

### Как включить MCP

**Инструменты → MCP-инструменты**:

1. добавьте сервер;
2. укажите URL и токен;
3. включите **🔧 MCP** в чате.

Инструменты плагинов работают отдельно от переключателя MCP: они доступны, если провайдер поддерживает tool calling.

## 15. Отладка и типичные ошибки

### Плагин не появился после импорта

Причины:

- синтаксис Lua сломан;
- нет `return` в конце;
- файл не текст;
- расширение не `.devai`.

Что делать:

1. Проверьте `return` в конце.
2. Убедитесь, что таблица закрыта `}`.
3. Проверьте кавычки.
4. Попробуйте минимальный плагин:

```lua
return { name = "Тест" }
```

### Команда не появилась

Причины:

- `commands` не таблица;
- у команды нет `name`;
- у команды нет `run` и нет `prompt`.

Проверьте:

```lua
commands = {
  { name = "/test", run = function(input) return input end }
}
```

### Инструмент не вызывается

Причины:

- провайдер не поддерживает tool calling;
- выбран не OpenAI-совместимый формат;
- `description` непонятный;
- `parameters` — невалидный JSON;
- имя инструмента с пробелами.

Что делать:

1. Проверьте провайдера.
2. Сделайте описание конкретным.
3. Проверьте JSON Schema.
4. Попросите модель явно вызвать инструмент.

### Ошибка `attempt to index a nil value`

Вы обращаетесь к `nil`:

```lua
args.text  -- если args.text == nil
```

Используйте:

```lua
local text = args.text or ""
```

### Ошибка `attempt to call a nil value`

Функция не существует или не загружена. Проверьте имя: `string.upper`, а не `string.Upper`.

### Ошибка `unexpected symbol near ...`

Синтаксис Lua. Частые причины:

- забыта `end`;
- забыта `}`;
- незакрытая кавычка;
- запятая после последнего элемента (в Lua допустима, но лучше убрать).

### Плагин завис

Скорее всего, бесконечный цикл. Перезапустите приложение и исправьте код. Не используйте `while true do end`.

### Инструмент вернул пустоту

Проверьте, что `run` возвращает строку:

```lua
return "результат"
```

### Русский текст считается неправильно

`string.len` считает байты. Для количества слов используйте `string.gmatch(text, "%S+")`.

## 18. FAQ

### Это настоящий код или просто промпт?

Настоящий. Lua выполняется через LuaJ. Промпт-плагины (DPL) тоже поддерживаются, но это другой, упрощённый режим.

### Может ли плагин украсть ключ?

Нет. Плагин не получает ключи и не имеет доступа к Java/сети.

### Может ли плагин отправить данные в интернет?

Нет. `io`, `os`, `require`, `luajava` отключены. Для сети используйте MCP.

### Почему ИИ не вызывает мой инструмент?

Скорее всего, провайдер не поддерживает tool calling или описание непонятное. Проверьте провайдера и текст `description`.

### Работают ли инструменты с Anthropic/Gemini?

Сейчас агентный цикл инструментов реализован для OpenAI-совместимых API. Для других форматов плагин останется доступен как команда, но автоматический вызов инструмента может не работать.

### Можно ли использовать несколько плагинов?

Да. Все команды появятся в меню, все инструменты уйдут модели.

### Можно ли вернуть таблицу из инструмента?

Технически да, но лучше вернуть строку. Модель ждёт текст.

### Есть ли доступ к файлам?

Нет.

### Есть ли `print`?

`print` может писать в stdout, но в Android это не удобно. Возвращайте строку.

### Почему `string.len` показывает больше символов?

Он считает байты UTF-8. Русская буква — 2 байта.

### Как сделать таймаут?

В песочнице нет `os.clock`. Приложение не убивает зависший Lua. Не пишите бесконечные циклы.

### Можно ли подключать библиотеки?

Нет. `require` и `package` отключены.

### Можно ли использовать `math.random`?

Да, `math` доступен.

### Можно ли использовать регулярные выражения?

В Lua есть шаблоны `string.find`, `string.gmatch`, `string.gsub`. Это не PCRE, но для многих задач хватает.

### Где скачать эту документацию?

**Инструменты → Документация по плагинам DevAI Studio → Скачать .md**.
