04 / ВОПРОСЫ

Коротко
о главном.

DevAI Studio бесплатный?

APK можно скачать бесплатно. Для облачных провайдеров нужен свой API-ключ; локальные модели работают на устройстве без облака. Часть функций может быть в Premium.

Почему APK такой большой?

Внутри обои, набор иконок, шрифты, код приложения и нативная библиотека LiteRT-LM для локальных моделей. Это цена автономности.

Куда уходят данные?

Зависит от выбранного провайдера. Локальные модели не отправляют запросы наружу. Для облачных моделей действуют правила выбранного сервиса.

Vexel изменён?

Нет. Оригинальный конструктор Vexel не изменялся. Автор Vexel — t.me/cheburek_dev.

Где API для разработчиков?

На отдельной странице: DevAI Core API. Ключ создаётся в браузере, запросы совместимы с OpenAI Chat Completions.

Как приходят обновления?

Через GitHub Releases. Сайт читает последний релиз и обновляет версию и ссылку автоматически; в приложении есть окно обновления.
